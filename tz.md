# Архитектура программного средства: ИС «Хлебопекарня»

Архитектура построена по трёхуровневой модели:
1. Уровень представления: формы авторизации, главное меню, интерфейсы склада, рецептов, заказов и отчетов.
2. Уровень бизнес-логики: модули авторизации, складского учета, рецептов, производства и отчетов.
3. Уровень данных: База данных хлебопекарни для надежного хранения информации.
