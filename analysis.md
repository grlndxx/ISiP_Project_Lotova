# Анализ предметной области: ИС «Хлебопекарня»

Проект предназначен для автоматизации процессов хлебопекарни: закупки сырья, учета производства по рецептам, складского учета готовой продукции, а также приема и выполнения заказов клиентов. 
Без автоматизации возникают сложности с поиском складских остатков и обработкой заказов. Новая информационная система повысит скорость работы и точность учета.
